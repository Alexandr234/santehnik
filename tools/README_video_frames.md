# Раскадровка видео для анализа нейросетью

Скринит каждое видео каждые **2 секунды** (30 кадров/минуту, 300 кадров на 10 минут),
складывает кадры **по порядку** и собирает **PDF** (сетка с таймкодами) + **ZIP**.
PDF/ZIP закидываете в нейросеть — она видит кадры по порядку и разбирает логику и стиль.

---

## Вариант «в один клик» (рекомендую) — `Раскадровка.command`

Один файл. **Ничего ставить руками не нужно**: `ffmpeg` он скачивает сам один раз
(без Homebrew и пароля), PDF собирает встроенным в macOS `python3`.

### Как пользоваться
1. Положите видео в папку `~/Desktop/ФАБРИКА ВИДЕО`
   (или потом просто перетащите свою папку с видео на файл `.command`).
2. Первый раз, чтобы macOS разрешил запуск, выполните в Терминале один раз:
   ```bash
   chmod +x ~/Downloads/Раскадровка.command
   xattr -dr com.apple.quarantine ~/Downloads/Раскадровка.command
   ```
   (путь поправьте, если файл лежит не в «Загрузках»).
   Либо: правый клик по файлу → **Открыть** → **Открыть**.
3. Дальше — просто **двойной клик**. Откроется окно Терминала с прогрессом.

### Что получится
Внутри папки с видео появится `_РАСКАДРОВКА/`, и для каждого видео — своя подпапка:
```
_РАСКАДРОВКА/
  Видео_01/
    frames/             # все кадры по порядку: frame_00001.jpg, frame_00002.jpg …
    Видео_01_кадры.pdf  # сетка кадров с таймкодами, 30 кадров = 1 минута на страницу
    Видео_01_кадры.zip  # те же кадры архивом
```

### Настройки
Откройте `.command` в текстовом редакторе — вверху меняются:
`INTERVAL` (секунд между кадрами), `WIDTH` (размер кадра), `COLS`/`ROWS` (сетка PDF).

```bash
brew install ffmpeg
pip3 install pillow
python3 tools/video_frames.py "/Users/aleksandrtomilov/Desktop/ФАБРИКА ВИДЕО"
```
Флаги: `-i/--interval`, `--cols`, `--rows`, `--no-pdf`, `--no-zip`.
