# video_frames.py — раскадровка видео для анализа нейросетью

Скринит каждое видео из папки каждые 2 секунды (30 кадров/минуту, 300 кадров на 10 минут),
складывает кадры **по порядку** и собирает из них **PDF** (сетка с таймкодами) и **ZIP**.
PDF/ZIP удобно закинуть в нейросеть — она увидит кадры по порядку и разберёт логику и стиль.

## Установка (один раз, на Mac)

```bash
brew install ffmpeg
pip3 install pillow
```

## Запуск

```bash
# берёт папку "ФАБРИКА ВИДЕО" на рабочем столе по умолчанию
python3 tools/video_frames.py

# или указать папку явно
python3 tools/video_frames.py "/Users/aleksandrtomilov/Desktop/ФАБРИКА ВИДЕО"
```

## Что получится

Внутри папки с видео появится `_РАСКАДРОВКА/`, и для каждого видео — своя подпапка:

```
_РАСКАДРОВКА/
  Видео_01/
    frames/            # все кадры по порядку: frame_00001.jpg, frame_00002.jpg, ...
    Видео_01_кадры.pdf # сетка кадров с таймкодами, 30 кадров = 1 минута на страницу
    Видео_01_кадры.zip # те же кадры архивом
```

## Настройки

| Флаг | Значение | По умолчанию |
|------|----------|--------------|
| `-i, --interval` | секунд между кадрами | `2` |
| `--cols` / `--rows` | сетка PDF | `5` × `6` (= 30/страница) |
| `-o, --output` | папка результатов | `<input>/_РАСКАДРОВКА` |
| `--no-pdf` / `--no-zip` | не создавать PDF / ZIP | — |

Примеры: кадр раз в 1 секунду — `--interval 1`; только PDF — `--no-zip`.
