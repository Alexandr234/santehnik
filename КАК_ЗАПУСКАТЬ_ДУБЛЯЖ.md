# SRT GPT + Voicer Dubber — как запускать

Теперь ничего не нужно настраивать вручную. Виртуальное окружение и все
библиотеки скрипт создаёт и ставит сам при первом запуске.

## Ключи API (делается один раз)

Ключи больше не хранятся внутри скрипта (так безопаснее, и GitHub не даёт
загружать файлы с ключами). Есть два способа:

- **Проще всего:** при самом первом запуске двойным кликом скрипт сам спросит
  OpenAI и Voicer ключи и сохранит их в файл `dubber_keys.txt`. Больше вводить
  не нужно.
- **Вручную:** скопируй `dubber_keys.example.txt` в `dubber_keys.txt` и вставь
  свои ключи. Взять их можно из твоего старого файла
  `srt_gpt_voicer_dubber_v2_FIXED_BACKUP_DOMAIN.py` (там были переменные
  `OPENAI_API_KEY` и `VOICER_API_KEY`).

Файл `dubber_keys.txt` в репозиторий не попадает — он в `.gitignore`.

## Windows

1. Дважды кликни по файлу **`Запустить_дубляж_WINDOWS.bat`**.
2. Скрипт сам создаст окружение, поставит библиотеки и спросит:
   - путь к `.srt` файлу (можно просто перетащить файл в окно и нажать Enter);
   - язык: `RU`, `ES`, `PT` или `ALL`;
   - (необязательно) путь к видео;
   - папку для результатов.
3. Дальше всё идёт автоматически.

> Нужен установленный Python 3 (https://www.python.org/downloads/).
> При установке поставь галочку **«Add Python to PATH»**.

## macOS

1. Дважды кликни по файлу **`Запустить_дубляж_MAC.command`**.
   - Если macOS не даёт открыть («неизвестный разработчик») — кликни правой
     кнопкой → **Открыть** → **Открыть**.
2. Дальше так же, как в Windows: скрипт сам всё поставит и задаст вопросы.

## Запуск из терминала (как раньше, с аргументами)

Автозапуск окружения работает и здесь — просто вызови сам `.py`:

```bash
python srt_gpt_voicer_dubber_v2.py --srt input_en.srt --lang RU
python srt_gpt_voicer_dubber_v2.py --srt input_en.srt --lang ALL
python srt_gpt_voicer_dubber_v2.py --srt input_en.srt --lang RU --video video_en.mp4
```

## Что происходит при первом запуске

- Рядом со скриптом создаётся папка **`.venv_dubber`** — это его окружение.
- В неё ставятся: `openai`, `requests`, `pysrt`, `pydub`, `tqdm` и переносимый
  `ffmpeg` (`imageio-ffmpeg`), поэтому отдельно ставить ffmpeg не нужно.
- Второй и последующие запуски идут быстро — установка больше не повторяется.

Если что-то пошло не так — удали папку `.venv_dubber` и запусти снова:
окружение пересоздастся с нуля.
