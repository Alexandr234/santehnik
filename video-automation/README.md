# Автоматизация рекламных рилсов для бота «Photo LIKE | ИИ ФОТО»

Конвейер для массового производства роликов по структуре референса:

```
[1] Хук (~2 сек)          [2] Демо бота (~3.3 сек)      [3] Результат (~2 сек)
оживлённое ИИ-фото         постоянный скринкаст           итоговое фото
+ текст-крючок             (один раз записан)             с медленным зумом
```

## Процесс

### Этап 1 — идеи (в чате с Claude)
Claude генерирует партии идей → файлы в `ideas/batch-NN.md`. Каждая идея:
хук-текст + готовый промпт для бота + промпт оживления. Владелец отсматривает
и помечает утверждённые.

### Этап 2 — производство ассетов (по утверждённой идее)
1. **Фото** — отправить промпт идеи в бот Photo LIKE со своим фото → `final.jpg`
2. **Оживление** — загрузить `final.jpg` в Kling / Runway / Hailuo с промптом
   оживления из идеи → `hook.mp4` (5–10 сек, нужны первые ~2)
3. **Демо** — `bot_demo.mp4` записывается один раз и переиспользуется

### Этап 3 — автомонтаж
```bash
./make_reel.sh \
  -a hook.mp4 \            # оживлённое фото
  -t hook_text.txt \       # текст хука (переносы строк = переносы в кадре)
  -d bot_demo.mp4 \        # постоянный скринкаст
  -p final.jpg \           # итоговое фото
  -m music.mp3 \           # музыка (опционально)
  -o reel_arrest.mp4
```

Скрипт сам: приводит всё к вертикали 1080×1920/30fps, накладывает текст
(белый с чёрной обводкой, верхняя треть кадра — как в референсе), делает
медленный зум на финальном фото, склеивает, подкладывает музыку с фейдом.

Длительности сегментов настраиваются: `-1 2.0 -2 3.3 -3 2.0` (сек).

Требования: `ffmpeg`, `python3`, шрифт с кириллицей (по умолчанию
DejaVuSans-Bold; свой — через `-f путь/к/шрифту.ttf`).

```
│   └── batch-01.md
└── assets/            — постоянные ассеты (bot_demo.mp4, музыка) — добавить
```

## Возможное развитие
- Полная автоматизация генерации: фото и оживление через API (fal.ai / Kling API),
  очередь идей → готовые ролики без ручных шагов
- Пакетный режим: CSV с идеями → N роликов за один запуск
- Автоперебор хук-текстов для A/B-тестов на одном и том же видео
