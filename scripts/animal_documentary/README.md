# Скрипты «документального завода» (животные) — версия с паузами и звуком природы

Обновлённый конвейер: озвучка → промпты → генерация видео → финальная сборка.
Два главных изменения по сравнению со старой версией:

## 1. Паузы между фразами с кадрами животных (как в настоящей документалке)

- `doc_prompt_pipeline_universal_ru_de_es_pl.py` теперь вставляет **паузы-перебивки
  (b-roll)** между фразами диктора. На каждую паузу генерируется отдельный промпт
  с кадрами животных/природы (без слов — зритель просто смотрит и слушает природу).
- Файлы `image_times_*.txt` и `prompts_*.txt` получили расширенный формат строк:

  ```
  001 | 00:00:00,000 --> 00:00:06,640 | duration: 6.64s | type: speech | src: 00:00:00,000 --> 00:00:06,640
  002 | 00:00:06,640 --> 00:00:08,840 | duration: 2.20s | type: broll
  ```

  - `type: speech` — фраза диктора; `src` показывает, где эта фраза лежит в **исходной** озвучке;
  - `type: broll` — пауза-перебивка: диктор молчит, на экране животные.
- `video_creator_times_autovenv_no_subs_realistic.py` читает эти поля, **режет озвучку
  по фразам и вставляет тишину** на время перебивок — голос точно совпадает с растянутой шкалой.
- Управление в пайплайне промптов: `--no-pauses`, `--pause-seconds 2.2`, `--pause-every 1`
  (или env: `DOC_PAUSES=0`, `DOC_PAUSE_SECONDS`, `DOC_PAUSE_EVERY`).
- **Старый формат таймингов полностью поддерживается**: без `type`/`src` всё работает как раньше.

## 2. Видео со звуком: только оригинальные звуки природы

- Во все финальные промпты (пайплайн + оба генератора видео + ремонтник) добавлен
  аудио-блок: *только натуральные звуки природы, записанные «на месте» — ветер, вода,
  крики видимых в кадре животных; строго БЕЗ человеческой речи, закадрового голоса,
  пения, музыки и саундтрека*. Блок не дублируется, если уже пришёл из файла промптов.
- Сборщик видео больше **не выбрасывает звук клипов**: родной звук каждого
  сгенерированного видео собирается в ambient-дорожку по той же шкале, что и видеоряд
  (с теми же кроссфейдами), затем:
  - под фразами диктора природа автоматически **приглушается** (sidechain ducking);
  - в паузах-перебивках природа звучит **в полный голос**.
- Настройки в конфиге сборщика: `KEEP_CLIP_AUDIO`, `AMBIENT_VOLUME`,
  `DUCK_THRESHOLD / DUCK_RATIO / DUCK_ATTACK_MS / DUCK_RELEASE_MS`.
- Если у клипов нет аудиодорожки, сборка автоматически падает в старый режим
  «только озвучка».

## 3. Точный монтаж по реальному звуку (исправление разрезанных слов)

- Таймкоды Whisper неточные: разрез по ним мог попасть в середину слова
  («обезь…яна»), а естественные паузы дыхания между фразами терялись.
- Теперь озвучка режется **только в местах пауз-перебивок** и **только по реальной
  тишине** (ffmpeg silencedetect) рядом с границей фраз. Между фразами без паузы
  озвучка не режется вовсе — ни одна секунда звука не теряется, длительности
  видеосегментов подгоняются под фактические куски звука.
- `analyze_voiceover_cutplan.py` — отдельный анализатор: разбирает ОЗВУЧКА/*.mp3,
  печатает отчёт по всем разрезам и пишет чёткий план `ПРОМПТЫ/cutplan_<xx>.json`.
  Сборщик автоматически использует этот план (а без него делает тот же анализ сам).

## Порядок запуска

1. `doc_prompt_pipeline_universal_ru_de_es_pl.py` — транскрипция и промпты (+ паузы).
2. `flow_visual_batch_generator_realistic.py` (или `flower_veo31_...`) — генерация
   видео по всем позициям, включая b-roll перебивки (нумерация сквозная, парсер
   понимает новые строки без изменений).
3. `flow_repair_missing_videos_100percent.py` — добивка пропусков до 100%.
4. `analyze_voiceover_cutplan.py` — (опционально, но рекомендуется) точный план
   монтажа по реальной тишине озвучки.
5. `video_creator_times_autovenv_no_subs_realistic.py` — финальная сборка:
   видеоряд + голос с паузами + природа из клипов.

Вспомогательные:
- `run_documentary_factory.py` — оркестратор: запускает шаги по порядку.
- `remontage_fix_pauses.py` — перемонтаж готового визуала: двигает паузы
  к границам предложений без перегенерации.
