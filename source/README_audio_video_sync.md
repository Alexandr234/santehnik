# Синхронизация аудио и роликов: тайм-коды по смыслу + автомонтаж

`audio_video_sync_montage.py` — 4-й, финальный скрипт к существующему конвейеру
генерации AI-видео. Он берёт готовые 8-секундные ролики и озвучку, определяет
**в какой момент какой ролик должен стоять** (по смыслу текста), и собирает
итоговый монтаж с наложенным аудио.

## Место в конвейере

```
scenario.txt
  │
  ├─▶ master_prompt_pipeline...py        → generated_prompts.json  (сцены + sentence_indexes + block_text)
  │                                         generated_image_prompts.txt
  │
  ├─▶ media_gen_..._flower.py            → КАРТИНКИ/0001.png, 0002.png, ...
  │
  ├─▶ video_from_local_images...py       → ВИДЕО/0001.mp4, 0002.mp4, ...  (~8 сек каждый)
  │
  └─▶ audio_video_sync_montage.py  ◀── ЭТОТ СКРИПТ
          ЭТАП 1 → video_timecodes.json / .txt   (когда какой ролик)
          ЭТАП 2 → final_montage.mp4              (готовое видео + звук)
```

Нумерация сквозная: `global_scene_index = 1` → `0001.png` → `0001.mp4`.

## Как определяются тайм-коды «по смыслу»

Привязку «сцена ↔ кусок текста» уже сделал `master_prompt_pipeline` — у каждой
сцены в `generated_prompts.json` есть `sentence_indexes` (какие предложения
сценария она иллюстрирует) и `block_id`. Скрипт добавляет к этому **реальное
время** из аудио:

1. **Whisper-транскрибация** аудио с таймкодами слов/сегментов.
2. **Выравнивание** `scenario.txt` на транскрипт (`difflib`) → у каждого
   предложения появляется реальный `start`/`end`.
3. Сцена знает свои предложения → получает реальный таймкод. Несколько сцен
   одного блока распределяются по времени блока.
4. Слоты делаются непрерывными и монотонными, покрывая всё аудио.

### Режимы деградации (всё graceful)
- нет OpenAI-ключа / нет аудио → тайминги по символам (как в master-скрипте);
- `scenario.txt` расходится с аудио (coverage ниже порога) → пропорциональный откат;
- нет `scenario.txt` → ролики раскидываются по сегментам Whisper по порядку;
- нет `ffmpeg` → сохраняются только тайм-коды, монтаж можно собрать позже.

## Монтаж

Каждый ролик подгоняется под свой слот:
- слот **короче** ролика → обрезка;
- слот **длиннее** ролика → `FILL_MODE`: `freeze` (фриз последнего кадра, по
  умолчанию), `slow` (замедление), `loop` (зацикливание);
- ролик отсутствует → чёрный слот нужной длины.

Клипы разных разрешений нормализуются к общему кадру, склеиваются по порядку,
сверху накладывается оригинальное аудио. Итоговая длина = длине аудио.

## Запуск

```bash
export OPENAI_API_KEY="sk-..."        # или положить ключ в ПРОМПТЫ/openai_key.txt

python audio_video_sync_montage.py                    # тайм-коды + полный монтаж
python audio_video_sync_montage.py --preview           # ТЕСТ: только первая минута -> final_montage_preview.mp4
python audio_video_sync_montage.py --preview 30        # тест первых 30 секунд
python audio_video_sync_montage.py --timecodes-only   # только этап 1
python audio_video_sync_montage.py --render-only       # только монтаж по video_timecodes.json
python audio_video_sync_montage.py --render-only --preview   # быстрый превью-монтаж по готовым тайм-кодам
```

**Режим предпросмотра (`--preview [СЕК]`, по умолчанию 60)** монтирует только
первые N секунд в отдельный файл `final_montage_preview.mp4` — чтобы быстро
проверить результат, не рендеря весь ролик и не нагружая машину. Тайм-коды при
этом считаются по всему аудио (превью показывает реальный результат), а полный
`final_montage.mp4` не перезаписывается. То же самое включается через
`PREVIEW_SECONDS=60`.

Нужен установленный **ffmpeg** (на macOS: `brew install ffmpeg`). Пакет `openai`
уже используется в master-скрипте.

## Основные настройки (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PROMPTS_BASE_DIR` | `/Users/aleksandrtomilov/Desktop/ПРОМПТЫ` | Базовая папка проекта |
| `OPENAI_API_KEY` | — | Ключ для Whisper (или файл `openai_key.txt`) |
| `WHISPER_MODEL` | `whisper-1` | Модель транскрибации |
| `PREVIEW_SECONDS` | — | Смонтировать только первые N секунд (тест). Аналог `--preview` |
| `CLIP_SECONDS` | `8` | Длина исходных роликов |
| `MIN_SLOT_SECONDS` | `1.2` | Минимальная длина слота под ролик |
| `FILL_MODE` | `freeze` | Заполнение длинного слота: `freeze`/`slow`/`loop` |
| `TARGET_FPS` | `30` | Кадры/сек итогового видео |
| `TARGET_RESOLUTION` | из 1-го ролика | Напр. `1920x1080` |
| `ALIGN_MIN_COVERAGE` | `0.45` | Порог доверия выравниванию сценария на аудио |

## Выходные файлы (в папке ПРОМПТЫ)

- `video_timecodes.json` — машинный список слотов (старт/конец/длительность/сцена);
- `video_timecodes.txt` — читаемая версия для проверки глазами;
- `audio_transcript.json` — кэш транскрипта (чтобы не гонять Whisper повторно);
- `final_montage.mp4` — готовое видео со звуком.
