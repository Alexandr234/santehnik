ЯПОНИЯ АВТОМАТИЗАЦИЯ — автосборка ролика (тема: японские привычки)
====================================================================

Это точная копия твоего пайплайна «ИСТОРИЯ АВТОМАТИЗАЦИЯ», но:
  • полностью переведена на тему «японские привычки / осознанная жизнь / минимализм»;
  • сменён СТИЛЬ картинок — тёплая уютная 2D редакторская иллюстрация
    (мягкие формы, тонкий мягкий контур или без контура, мягкие тени и тёплый свет,
    палитра: кремовый, охра, терракота, шалфейный, тёплое дерево, пыльно-бирюзовый),
    персонажи — реалистичные, но упрощённые (НЕ стикмены), уютный минималистичный
    интерьер в японском духе. Это стиль из твоего PDF-референса;
  • изменена ЛОГИКА генерации кадров — вместо крикливых типов (big_text / cross_out /
    simple_chart) теперь спокойные типы:
        scene   — уютная сюжетная сцена (по умолчанию, ~80%)
        object  — крупный план одного предмета на чистом фоне
        concept — концептуальная метафора с мягким тёплым свечением
        contrast— спокойное «до/после»: беспорядок → порядок
  • все пути ведут в  /Users/aleksandrtomilov/Desktop/ЯПОНИЯ АВТОМАТИЗАЦИЯ

СТРУКТУРА ПАПОК
--------------
  СЦЕНАРИИ/         — сюда положи текст сценария: RU.txt и EN.txt
  ОЗВУЧКА/          — сюда падает готовая озвучка (RU.mp3 / EN.mp3)
  ПРОМПТЫ/          — сюда падают промпты и тайминги (ru_RU_prompts.txt и т.д.)
  ВИЗУАЛ/
     RU_SCENE_LOCK/ — сгенерированные картинки RU
     EN_SCENE_LOCK/ — сгенерированные картинки EN
  ГОТОВЫЕ ВИДЕО/    — финальные mp4
  МОНТАЖ/           — сюда положи звук клика мыши: МЫШЬ.MP3

ПОРЯДОК ЗАПУСКА (как и раньше)
-----------------------------
0) Один раз создай окружение и поставь зависимости:
      cd "/Users/aleksandrtomilov/Desktop/ЯПОНИЯ АВТОМАТИЗАЦИЯ"
      python3 -m venv venv
      source venv/bin/activate
      pip install openai requests numpy opencv-python tqdm
      brew install ffmpeg           # если ffmpeg ещё не стоит

1) Озвучка (RU → EN):
      python3 japan_voicer_batch_tts_RU_EN.py
   (нужны файлы СЦЕНАРИИ/RU.txt и СЦЕНАРИИ/EN.txt)

2) Промпты + тайминги (транскрибация озвучки, нарезка на кадры 1–3 сек):
      export OPENAI_API_KEY="sk-..."
      python3 japan_prompt_pipeline.py

3) Генерация картинок (нужен ключ fast-gen):
      export FAST_GEN_API_KEY="ТВОЙ_КЛЮЧ"
      python3 japan_fastgen_image_generator_RU_EN_20workers.py

4) Монтаж (в один клик, пересобирает заново):
      python3 japan_video_creator_ONE_CLICK_SAFE.py

КЛЮЧИ / НАСТРОЙКИ
----------------
  • OPENAI_API_KEY   — для транскрибации и генерации промптов (japan_prompt_pipeline.py)
  • FAST_GEN_API_KEY — для генерации картинок (japan_fastgen_image_generator...)
  • Ключ Voicer уже вписан в japan_voicer_batch_tts_RU_EN.py (как в оригинале),
    при необходимости замени на свой. UUID голосов RU/EN оставлены прежними.

Если хочешь ещё сильнее подкрутить стиль картинок — правь строки STYLE_GUARD_RU /
STYLE_GUARD_EN в japan_fastgen_image_generator_RU_EN_20workers.py и STYLE_PREFIX_SHORT
+ системные промпты в japan_prompt_pipeline.py.
